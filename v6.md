# v6 — ResearchOS v0.7 Scientific Writing and Publication Engine

**Status: Complete**

## Scope

Generate editable research documents from approved, structured records for research papers, reviews, systematic reviews, conference papers, reports, proposals, theoretical and experimental work. Add citation management and validation, configurable publication templates, Markdown/LaTeX/DOCX/PDF exporters, preview, and structural consistency checks.

## Acceptance checks

- Sections follow the selected document type and research material; missing results are never filled with invented values.
- Citations resolve to stored, verified source records or are flagged for review.
- Exporters use real templates and produce valid files with citations and figures/tables where supported.
- Researchers can review and edit before export; template compliance is not claimed without checking actual requirements.

## Remaining

## Implemented so far

- Added real section templates for research articles, literature reviews, systematic reviews, proposals, reports, conference papers, and theoretical papers.
- Draft generation accepts only selected records: source-linked claims, approved study designs, successful experiment records, and saved descriptive prediction evaluations. Citations retain the local PDF ID, page number, document hash, and claim review state. Unreviewed citations are marked for review and verified citations are rechecked before approval/export.
- Drafts use explicit placeholders where researchers have not supplied an abstract, rationale, methods, results, discussion, or limitations. Recorded experiment logs and metric values are identified as captured/descriptive data, not independently validated scientific findings. Confusion matrices, metric summaries, and sampled regression values are represented as tables where available.
- Added editable Markdown drafts, revision history, researcher approval/rejection/revision actions, and export gating against the exact approved content hash.
- Added Markdown, LaTeX, DOCX, and PDF exporters with download hash checks. DOCX uses an OOXML package and PDF uses a bounded built-in writer; no optional authoring service or API key is needed.
- Added deterministic confusion-matrix and actual-versus-predicted SVG figures from saved evaluation records. Figures are embedded in Markdown, represented with TikZ/PGFPlots in LaTeX, packaged as SVG media in DOCX, and drawn as vector shapes in PDF. Metric tables and selected sampled values accompany the figures.
- Added browser and HTTP routes for draft creation, editing, review, and export.
