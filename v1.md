# v1 — ResearchOS v0.2 Knowledge Engine foundation

**Status: Complete**

## Delivered

- Shared `Paper`, `PaperProvenance`, `ProviderOutcome`, and `ResearchSearchResult` records.
- OpenAlex and Crossref adapters implementing the same `search(query, limit) -> list[Paper]` contract.
- Multi-provider aggregation, normalized DOI deduplication, and provenance retention.
- Distinct complete, partial, failed, and skipped search states persisted to JSON run records.
- Existing CLI, web form, and Markdown brief flow retained.
- Offline tests for parsing, provider failures, provenance, DOI edge cases, persistence, and CLI behavior.

## Verification

`PYTHONPATH=src python3 -m unittest discover -s tests -v` passed all 19 tests when v0.2 was delivered.

## Feedback recorded for later

1. Make `--max-papers` a cap on total unique results, rather than a per-provider cap.
2. Keep DOI-less papers separate until conservative author/title/year matching can create candidates for manual review.
3. Consider parallel provider requests with reliable timeout, cancellation, and failure handling.

These are follow-ups, not features of v0.2.

## Remaining

No v0.2 acceptance work remains. The next release is v0.3, the Evidence Intelligence Engine. Live provider availability was not covered by offline tests.
