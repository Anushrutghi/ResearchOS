# v5 — ResearchOS v0.6 Multi-Agent Research Runtime

**Status: Complete**

## Scope

Add a typed agent registry/runtime, task graph/state machine, structured messages, provider/model routing, tool permissions, usage tracking, retries, durable/resumable workflows, specialized research agents, and human approval checkpoints.

## Acceptance checks

- Inputs and outputs validate against schemas; each task has status and source provenance.
- Agents access tools only through explicit permissions and cannot directly rewrite trusted records.
- Recoverable workflows resume after restart; failures and model/API usage are recorded.
- Researchers can approve, reject, edit, or request revisions for major decisions.

## Implemented so far

- Added an agent registry and bounded JSON Schema validator for structured task inputs and outputs, plus ordered task graphs with explicit dependencies.
- Added `AgentContext` as the only tool interface exposed to registered agents. Tool calls require an agent-declared permission; task handlers do not receive a workflow store or direct record-write interface.
- Added atomic, durable workflow records, provider/model/usage metadata, tool-call logs, task provenance, failure records, interrupted-task recovery, and a four-attempt retry ceiling.
- Added approval gates with researcher approve, edit, reject, and revision actions. Downstream tasks receive completed/approved upstream outputs only after dependency gates are satisfied.
- Added a deterministic local research planner and an optional OpenAI-compatible structured-output adapter. AI remains disabled unless a valid provider, model, and key are configured; browser use confirms the outbound request and keeps the output provisional until review.
- Added browser and HTTP workflows to create, inspect, resume, and review saved plans.

## Remaining

The v0.6 acceptance checks are complete. Provider support is limited to the existing OpenAI-compatible chat-completions shape; other providers require an adapter. Core agents remain usable without credentials.
